# MyTodo

一个待办事项（Todo）项目。

## 简介

本项目用于记录和管理日常待办事项。目前仓库刚刚初始化，功能正在陆续补充中。

## 功能规划

- [ ] 新增 / 编辑 / 删除待办事项
- [ ] 标记完成状态
- [ ] 按优先级与截止日期排序
- [ ] 数据本地持久化

## 快速开始

```bash
git clone https://github.com/ykxddtsg/MyTodo.git
cd MyTodo
```

> 具体的安装与运行方式会随技术栈确定后补充到此处。
